本文件把电源/信号映射、裸铜接触面和端部尺寸变成可检查的要求。**当前没有样件，也没有唯一的显示板装配坐标，因此不发布排线长度或制造放行结论。** 机器可读定义、当前两块 PCB 的 SHA 及来源见 [ffc-interface.json](ffc-interface.json)。本文件不改变 PCB、原理图或既有 BOM。

## 2. 接触面方向的推导

采用八根平行、无交叉导体的普通 FFC，**摊平后两端接触露铜位于同一材料面**。Molex 对此称 Type A；供应商字母命名可以不同，采购图必须画出两个露铜面。该选型与两板都使用同一底接触接头共同实现 Main n 对 Ext 9-n。

这不是仅凭商品标题得出的判断。在每个接头定义：d 为排线从接头向外的方向，w 为 pin1 指向 pin8 的方向，n 为 PCB 正面法向。两端相同受控接头的局部关系均为 `d × w = -n`。连续线缆沿 A 端向外、沿 B 端向内；两端采用相同材料接触面时，导体编号轴在 A 与 w 同向、在 B 与 w 反向，因此接头编号倒序。两板整体旋转或倾斜不改变该局部编号关系，但会改变排线能否在壳内布置。

两端露铜位于不同材料面的无交叉排线会形成 Main n 对 Ext n，**不符合本电路**。例如主板 MOSI 会对到显示板 GND。不得靠强折排线或倒插接触面来尝试纠正。若使用交叉 FPC、转接板或不同接触手性的连接器，本推导不适用，必须重新给出整条映射。

Molex Type A / D 的面定义见其 [PS-15020-001 Rev F](https://www.molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/productspecificationpdf/150/15020/PS-15020-001-001.pdf)第 3 页。此处电路映射是对当前两端实际封装的工程推导，仍须用被动夹具实测 8×8 导通矩阵确认成品。

## 4. 长度与壳内路径

当前显示板与上壳尚未建立唯一的装配变换，两个历史倾角也不一致。因此不能从两个 PCB 的各自 XY 坐标直接算出板间距离，不能把社区约 60mm 当作最终长度。

待锁定输入包括：两板刚体装配变换、成品板厚、连接器实际插入止挡/出线方向、LCD 与尾排包络、连接器开盖扫掠、壳筋、装配顺序、供应商允许的静态弯曲半径及补强区禁弯长度。

统一按两端切口的 tip-to-tip 长度定义：

`L = A端插入长度 + B端插入长度 + Σ直线段 + Σ(中性层弯曲半径 × 弯曲角弧度) + 装配余量`

插入长度必须取接头图纸/实际止挡，不把裸铜长度当插入长度。余量是明确的可容纳服务弯，不是任意多出的线长；还需验证最长公差的排线不会顶压器件或壳体、最短公差的排线不受拉力。

Molex 规格中的 3mm 直径冷绕试验、手动折叠试验和 R=10mm 寿命试验是各自测试条件，**没有直接给出本装配允许的最小永久弯曲半径**，不得任取其中一个数作为整机放行依据。

## 6. 实物闭合步骤

1. 使用两个**无 IC、无电源连接的被动 FH12 测试夹具**，确认端部尺寸、铜面朝向、全部插入与锁扣闭合。切勿先把未知排线插在整机上通电。
2. 测量 8×8 导通矩阵：仅允许 1↔8、2↔7、3↔6、4↔5、5↔4、6↔3、7↔2、8↔1。扣除表笔电阻后各目标路径应小于 1Ω；其他路径不得出现低阻。这个 1Ω 是抓错线/断线的工程筛查门槛，不是对接头接触电阻的认证。
3. 整机不通电试装，验证插入、锁闭、开盖均可操作；排线没有拉力、锐折、与裸铜/焊点/壳筋相擦，闭壳不产生预载。锁定路径后发布 L 和公差。
4. 在限流上电后，按最终排线测试 10MHz 显示时序与画面稳定性，并与 SD/WiFi 并发及温度/电源范围验证结合。

已装器件的两板存在上拉电阻和半导体路径，不能照搬“被动线缆夹具”的绝缘/导通判据去判断整块电路板。没有实际样件结果时，步骤不得标记为通过。
