## 继续闭合所需的最小外部输入

1. **屏厂受控图纸**：确认当前具体屏批次的尾排展开/预折状态、触点金属面、12pin pitch/露铜尺寸公差、允许折弯位置/半径、COG/元件凸高、背胶及允许焊接条件。现有 11.10±0.5mm 裸屏背折图没有这些完整定义；不能靠选一个半径继续计算成已适配。
2. **装配注册**：明确显示板/屏体相对上壳的承托面、止挡和最终姿态。历史装配缓存约 22.39° 与上壳约 29.61° 的差异仍没有唯一注册证据。取得可信装配图或样件尺寸后，才能最终锁定 FFC 路径和长度。
3. **板厂回签**：接受指定模板、实际交付总厚范围、USB 内部孔到 land 距离、细线/孔环、ENIG、指定热孔处理及阻焊图。公开能力或模板不能代替本工程的 DFM 回复。
4. **一套实际样机**：完成供电波形、USB、屏幕/背光、SD/WiFi、传感器、温升及最终闭壳 RF 验收。现阶段没有相应读数、波形或装配照片。
