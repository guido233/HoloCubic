## 与本板对应的制造约定

依据 [JLCPCB 详细能力](https://jlcpcb.com/capabilities/pcb-)和 [过孔工艺说明](https://jlcpcb.com/help/article/pcb-via-covering)：

- 原型目标采用绿色阻焊、ENIG。六层工艺不选 HASL；最终镍金参数由板厂回签。
- 主板最小走线 0.1016mm、铜间距 0.127mm；145 个过孔的孔 / 铜盘组合为 0.25/0.45、0.25/0.46、0.30/0.50、0.30/0.60mm。最小过孔环宽 0.10mm。过孔与器件 PTH 的环宽和尺寸公差不能混为一类。
- GCT 四个器件 PTH 长槽的名义侧向环宽 0.20mm。器件 PTH 需按成品槽尺寸和槽公差审核，不能当作普通过孔处理或填孔。
- 两板项目采用绿色阻焊桥最小 0.10mm、阻焊开口到异网铜最小 0.09mm 的明确检查值。显示板 SMD 阻焊外扩由每边 0.05 改为 0.025mm；这只改变阻焊开口，不改变铜、锡膏、引脚或位置。该修订对应当前 LDI 开窗能力，仍需装配工艺确认。
- 主板 PICO 的 21 个 EP 热过孔与一般互连过孔必须在工艺图中分别标识。建议询价采用树脂填孔并铜盖镀、保持顶面 EP 和底面阻焊图；不能把“盖油”“油墨塞孔”“树脂填孔盖镀”当作同一种工艺。填孔材质、平整度及是否适用于全部指定孔由板厂回签，不能把 USB 槽或定位孔一并填掉。
- PICO 4.5mm 铜、4.0mm 阻焊开口、16 个 0.75mm 锡膏窗口不因填孔改变。80µm 钢网作为装配询价起点，最终锡量、回流和 EP 空洞标准须由装配厂确认。

## 询价必须逐项回签

1. 接受明确的 JLC06101H-3313 模板；列出实际压合材料及逐层成品厚度，说明 `compressionThickness`、外层成品铜、阻焊和订单总厚的计算关系。
2. 给出包含阻焊、成品铜及表面处理的总厚范围。工程机械筛查使用 0.90–1.10mm 范围；若交付口径或范围超出，先复核承托、USB 固定脚、壳体和屏排线，不直接生产。
3. 接受本板细线、孔环、异网间距、槽孔和沉金工艺。USB1 厂图内部 NPTH 到 land 约 0.1944mm，低于通用 0.20mm 约定，须单独接受或反馈可制造修改；不得靠全板放宽规则替代审核。
4. 审核源 Gerber / 钻孔的器件孔、普通过孔和 PICO 热孔分类，回签哪些孔填孔盖镀、哪些保持开孔，以及阻焊图能否保持；提供生产文件确认图。
5. 对受控天线工程 land、密集器件及裸屏焊接工艺给出装配可接受结论。未签回前，本文件是完整询价条件，不能充当板厂已经确认的证据。

两层显示板的名义采购厚度同样需明确为 1.0mm；历史 CAD 的约 1.071118mm 几何不是板厂厚度保证。显示板最终变更及总厚定义随其独立工程记录复核，不套用主板的六层材料表。
